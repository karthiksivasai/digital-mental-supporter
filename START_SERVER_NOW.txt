IF YOU GET ERRORS:

Error: "No module named 'uvicorn'"
  → Run: pip install uvicorn fastapi

Error: "No module named 'app'"
  → Make sure you're in the backend folder
  → Check: ls app/main.py

Error: "Port already in use"
  → Run: lsof -ti:8000 | xargs kill -9
  → Then try again
